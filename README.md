
# Java Chat Application

A simple chat application built in Java with server-client architecture.

## Features
- TCP/IP based communication
- Multi-threaded server handling multiple clients
- GUI client interface
- Real-time messaging

## Project Structure
- **ChatApplication.java** - Main entry point for the application
- **ChatServer.java** - Server implementation
- **ChatClient.java** - Command-line client
- **ChatClientGUI.java** - GUI-based client
- **ClientHandler.java** - Handles individual client connections on the server

## How to Run

### Starting the Server
```bash
javac *.java
java ChatApplication
# Select option 1 to start the server
```

### Starting a Client
```bash
java ChatApplication
# Select option 2 to start a client
```

Or directly:
```bash
java ChatClient
```

## Requirements
- Java 8 or higher
